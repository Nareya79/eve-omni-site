FAQ

Does it work with Stream Deck / Stream Dock?Geht es mit Stream Deck / Stream Dock?

Yes. EVE Omni brings a plugin for the Elgato Stream Deck (incl. Stream Deck + with dials) and the MiraBox Stream Dock (N4 and others). Turn it on under Settings › Program › Stream keys and click “Install plugin”. The keys only talk to EVE Omni on your own PC (127.0.0.1) – they never send input to the game.Ja. EVE Omni bringt ein Plugin für das Elgato Stream Deck (auch Stream Deck + mit Drehknöpfen) und das MiraBox Stream Dock (N4 und andere) mit. Einschalten unter Einstellungen › Programm › Stream-Tasten und „Plugin installieren“ klicken. Die Tasten sprechen nur mit EVE Omni auf deinem eigenen PC (127.0.0.1) – sie senden nie Eingaben ans Spiel.

Is EVE Omni allowed by CCP?Ist EVE Omni von CCP erlaubt?

EVE Omni uses only CCP's official, public interfaces (ESI and EVE SSO) like other third-party tools. It never reads or changes game files in memory and never sends keyboard or mouse input to the game. The client switcher only brings an EVE window to the front – one key, one window. It is a fan project and not affiliated with or endorsed by CCP.EVE Omni nutzt wie andere Drittanbieter-Tools nur die offiziellen, öffentlichen Schnittstellen von CCP (ESI und EVE SSO). Es liest oder verändert nichts im Spiel-Speicher und sendet keine Tastatur- oder Mauseingaben ans Spiel. Der Client-Umschalter holt nur ein EVE-Fenster nach vorne – eine Taste, ein Fenster. Es ist ein Fan-Projekt, nicht mit CCP verbunden und nicht von CCP unterstützt.

Does it cost anything?Kostet es etwas?

No. EVE Omni is free, with every feature, forever – no premium version. If you like it, you can send an in-game ISK donation, but you never have to.Nein. EVE Omni ist kostenlos, mit allen Funktionen, für immer – keine Premium-Version. Wenn es dir gefällt, kannst du eine ISK-Spende im Spiel schicken, musst aber nie.

Why does the login ask for so many permissions?Warum fragt der Login nach so vielen Berechtigungen?

Each area of the app needs read access to its own data – wallet for profits, assets for your items, skills for fees and so on. Only two permissions can do something in the game: setting your autopilot destination and opening an info window, and only when you click the button.Jeder Bereich braucht Lesezugriff auf seine Daten – Wallet für Gewinne, Assets für deine Items, Skills für Gebühren usw. Nur zwei Berechtigungen bewirken etwas im Spiel: Autopilot-Ziel setzen und ein Info-Fenster öffnen – und das nur, wenn du auf den Knopf klickst.

Where is my data stored?Wo werden meine Daten gespeichert?

Only on your PC, in the app's own folder. Nothing is uploaded to the developer. EVE Omni talks to CCP's ESI, zKillboard and DOTLAN for public data, and checks GitHub once a day for updates (can be turned off).Nur auf deinem PC, im Programmordner. Nichts wird an den Entwickler geschickt. EVE Omni fragt bei CCPs ESI, zKillboard und DOTLAN öffentliche Daten ab und schaut einmal am Tag bei GitHub nach Updates (abschaltbar).

Mac or Linux?Mac oder Linux?

The app is made for Windows. A browser version (single HTML file) is included and also works on other systems, with a few limits.Das Programm ist für Windows gemacht. Eine Browser-Version (eine HTML-Datei) liegt bei und läuft auch auf anderen Systemen, mit ein paar Einschränkungen.

I found a bug / have an ideaIch habe einen Fehler gefunden / eine Idee

Use the “Report bug” button in the app, open an issue on GitHub or ask on the EVE Omni Discord. Never post login tokens or codes.Nutze den Knopf „Fehler melden“ im Programm, öffne ein Issue auf GitHub oder frag im EVE-Omni-Discord. Poste nie Login-Tokens oder Codes.
